![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Write the code to do the following

- Take 3 inputs from the user - a string, an integer and a float.
- Store these inputs in a tuple
- Print the tuple to the console.

Check the sample input / output below for further clarity.

### Sample 1:
Input
Output

```
Python
10
3.14
```

```
('Python', 10, 3.14)
```

### Sample 2:
Input
Output

```
This
5
2.55
```

```
('This', 5, 2.55)
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-18T15:40:16.946Z  

```py
# cook your dish her
a=input()
b=int(input())
c=float(input())
tup=(a,b,c)
print(tup)
```
