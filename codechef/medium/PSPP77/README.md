## Solution

**Language:** Python  
**Runtime:** N/A

**Submitted:** 2026-08-14T15:39:07.221Z  

```py
two = 2
three = 3
four = 4
def square(i):
    return i*i
def cube(j):
    return j**3
print(square(two))
print(cube(two))
print(square(three))
print(cube(three))
print(square(four))
print(cube(four))
```
